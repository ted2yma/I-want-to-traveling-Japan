## 檔案命名規則

```
Y{年份後兩碼}S{季度}-{城市}.md
```

`S` 代表 Season（季度），例如 `Y26S4-Tokyo.md` 代表 2026 年第 4 季的東京旅行。

## 計劃書結構

每份計劃書大致包含以下章節：

1. **旅遊日期**：出發與回程日期
2. **航班資訊**：航空公司、航班號碼、起降時間、行李規定、票價
3. **住宿資訊**：飯店名稱、地址、電話、入住／退房時間、價格
4. **天氣預測**：各城市的溫度與天氣
5. **租車資訊**（視需要）：租車公司、車款、取還車地點與費用
6. **行程 wishlist**（選填）：想去但尚未排入的景點
7. **行程安排**：逐日行程
